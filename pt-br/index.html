Como funciona

Metas de longo prazo ficam no roadmap. O trabalho concreto do objetivo atual fica no plano privado. Os casos de teste ficam no COVERAGE.md como checkboxes que o agente reconcilia com testes reais via /coverage e stillmark coverage validate.

Companheiro de cobertura de testes

O COVERAGE.md é um checklist só com caixas, agrupado por área. Sem porcentagens nem blocos de texto - apenas casos marcados como happy, sad, edge ou security que registram o que de fato está testado.

Skill do agente

As instalações Cursor e Claude incluem a skill /coverage. Ela mostra ajuda, conduz o fluxo de update e edita o arquivo em linguagem natural.

Formato rígido

O stillmark coverage validate detecta texto legado, tags erradas e títulos vazios antes do commit.

Updates com git

O stillmark coverage update lista arquivos de código e de teste alterados desde o último commit do COVERAGE.md para o agente saber o que reconciliar.

Recursos

Linguagem natural e comandos

Adicione, adie, repriorize e mova itens sem editar markdown manualmente.

Escritas incrementais seguras

Os parsers preservam seções, IDs e histórico não relacionados.

Guardas de escopo e privacidade

Trabalho fora do escopo e conteúdo sensível no roadmap são bloqueados por padrão.

Modo long-running

Mudanças autorizadas no plano são salvas antes de o agente continuar.

Aprende com você

Mensagens de commit seguem o seu git log recente, sem template fixo de roadmap. Pré-visualize com stillmark git commit-style.

Git opcional no roadmap

Commit ou push só do ROADMAP.md quando você habilitar na configuração.

Companheiro COVERAGE.md

Valide, marque e adicione casos com stillmark coverage enquanto o /coverage trata linguagem natural.

Referência de comandos

Comando O que faz
stillmark roadmap add Adiciona item ao roadmap
stillmark plan add Adiciona tarefa ao plano ativo
stillmark add Infere roadmap ou plano
stillmark move … to plan Promove item do roadmap para o plano
stillmark long-running apply Aplica mudança no escopo durante a execução
stillmark git commit-style Pré-visualiza commit no estilo do seu git log
stillmark coverage init Cria um COVERAGE.md inicial
stillmark coverage validate Valida o formato de checkboxes (erro com exit 1)
stillmark coverage update Dicas de git desde o último commit do COVERAGE.md
