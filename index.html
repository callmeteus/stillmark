How it works

Long-term goals live in the roadmap. Concrete work for the current objective lives in the private task plan. Test cases live in COVERAGE.md as checkboxes your agent reconciles with real tests via /coverage and stillmark coverage validate.

Test coverage companion

COVERAGE.md is a checkbox-only checklist grouped by area. No percentages or prose blocks - just cases tagged happy, sad, edge, or security that track what is actually tested.

Agent skill

Cursor and Claude installs include a /coverage skill. It prints help, runs update workflows, and edits the file in plain language.

Strict format

stillmark coverage validate catches legacy prose, wrong tags, and empty headings before you commit.

Git-aware updates

stillmark coverage update lists source and test files that changed since the last COVERAGE.md commit so the agent knows what to reconcile.

Features

Natural language and commands

Add, defer, reprioritize, and move items without hand-editing markdown.

Safe incremental writes

Parsers preserve unrelated sections, IDs, and history.

Scope and privacy guards

Out-of-scope work and sensitive roadmap content are blocked by default.

Long-running mode

Authorized plan changes persist before the agent continues execution.

Learns from you

Commit messages follow your recent git history instead of a fixed roadmap template. Preview with stillmark git commit-style.

Optional git for roadmap

Auto-commit or push ROADMAP.md only when you enable it in config.

COVERAGE.md companion

Validate, check off, and add test cases with stillmark coverage while /coverage handles natural language.

Command reference

Command What it does
stillmark roadmap add Add a roadmap item
stillmark plan add Add a task to the active plan
stillmark add Infer roadmap vs plan
stillmark move … to plan Promote roadmap work into the plan
stillmark long-running apply Apply an in-scope change during execution
stillmark git commit-style Preview commit subject learned from git log
stillmark coverage init Create a starter COVERAGE.md
stillmark coverage validate Validate checkbox format (exit 1 on errors)
stillmark coverage update Git hints since last COVERAGE.md commit
