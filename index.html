Say what should change. Stillmark updates your roadmap, private task plan, and test checklist - plus embedded UI work through /stillmark, without hand-editing markdown.

Get started

Read and execute the markdown install guide at https://callmeteus.github.io/stillmark/install.md. Follow every step in that file to install Stillmark in this repository.

You can also select the prompt text and copy it yourself.

npx stillmark@latest init

Requires Node.js. Then run stillmark install --agent with your editor.

How it works

You describe what should change in chat. Stillmark keeps strategy, current work, and test tracking in three clear buckets.

  • Roadmap

    Shared with the team

    Long-term goals and priorities everyone can see in the repo.

  • Current plan

    Private on your machine

    Concrete tasks for what you are building right now, without publishing half-baked plans.

  • Test checklist

    Shared with the team

    A simple list of what is already covered by tests, so nothing important is forgotten.

Test coverage companion

COVERAGE.md is a checkbox-only checklist grouped by area. No percentages or prose blocks - just cases tagged happy, sad, edge, or security that track what is actually tested.

Via /stillmark coverage

/stillmark coverage shows help, /stillmark coverage update reconciles with git changes, and free text after /stillmark coverage edits the checklist in plain language.

Strict format

stillmark coverage validate catches legacy prose, wrong tags, and empty headings before you commit.

Git-aware updates

stillmark coverage update lists source and test files that changed since the last COVERAGE.md commit so the agent knows what to reconcile.

UI design companion

Point at what looks wrong in your running app and say what should change. Stillmark connects that feedback to your project instead of one-off tweaks.

Browser selection

Select an element on your local preview. The agent finds the matching screen or component in your codebase.

Via /stillmark design

Ask for spacing, type, color, or layout in plain language, or open with /stillmark design and a short brief.

Consistent polish

Design playbooks ship inside the stillmark skill so visual fixes stay aligned across sessions.

Planning companion

Turn vague intent into a shared roadmap and a private task list without hand-editing markdown for every change.

Natural language

/stillmark handles adds, deferrals, priorities, and moves. The CLI keeps sections, IDs, and history intact.

Scope and privacy

Sensitive roadmap content and work outside the current objective are flagged before they land in shared files.

Long-running work

When a task spans many agent turns, approved plan updates are saved so execution can continue safely.

Workspace preferences

Stillmark keeps task plans on your machine by default and asks once how much of .stillmark you want in git.

Private task plans

Active execution plans stay local. Only the roadmap and test checklist are meant for the team repo.

stillmark config

On first use, stillmark config status asks whether design reference files under .stillmark should be versioned with the project.

Optional roadmap git

When you enable it in config, Stillmark can commit or push ROADMAP.md for you - never the private plan folder.

Features

Natural language and commands

Add, defer, reprioritize, and move items without hand-editing markdown.

Safe incremental writes

Parsers preserve unrelated sections, IDs, and history.

Scope and privacy guards

Out-of-scope work and sensitive roadmap content are blocked by default.

Long-running mode

Authorized plan changes persist before the agent continues execution.

Learns from you

Commit messages follow your recent git history instead of a fixed roadmap template. Preview with stillmark git commit-style.

Optional git for roadmap

Auto-commit or push ROADMAP.md only when you enable it in config.

Step 2

Install agent templates

One stillmark skill handles planning, coverage, and design through /stillmark.

stillmark install --agent cursor

stillmark install --agent claude

stillmark install --agent codex

You can also select the prompt text and copy it yourself.

Command reference

Command What it does
stillmark init /stillmark init Create ROADMAP.md, stillmark.config.json, and .stillmark/plans/
stillmark install --agent cursor|claude|codex /stillmark install --agent cursor|claude|codex Install agent skills and shared instructions
stillmark config status /stillmark config status First-run prompt state and sharing flags (--json)
stillmark config set --design-system=… /stillmark config set --design-system=… Keep design-system local or version it in git (--prompted)
stillmark classify "…" /stillmark classify "…" Route ambiguous text to roadmap vs plan
stillmark add "…" /stillmark add "…" Add using classify, then roadmap or plan
stillmark roadmap add "…" /stillmark roadmap add "…" Add a public roadmap item
stillmark roadmap defer "…" /stillmark roadmap defer "…" Move a roadmap item to deferred
stillmark roadmap priority "…" <level> /stillmark roadmap priority "…" <level> Change roadmap priority
stillmark plan init [objective] /stillmark plan init [objective] Start TASK_PLAN.md for the current objective
stillmark plan add "…" /stillmark plan add "…" Add a task to the active plan
stillmark plan blocked "…" <reason> /stillmark plan blocked "…" <reason> Mark a plan task blocked
stillmark move "…" to plan /stillmark move "…" to plan Promote roadmap work into the plan (--confirm)
stillmark move "…" to roadmap /stillmark move "…" to roadmap Move work back to the roadmap (--confirm)
stillmark long-running apply "…" /stillmark long-running apply "…" Persist an authorized in-scope plan change
stillmark git commit-style "…" /stillmark git commit-style "…" Preview commit subject learned from git log
stillmark coverage init /stillmark coverage init Create a starter COVERAGE.md
stillmark coverage validate /stillmark coverage validate Validate checkbox format (exit 1 on errors)
stillmark coverage summary /stillmark coverage summary Print checklist stats without full validation noise
stillmark coverage update /stillmark coverage update List source and test files changed since last COVERAGE commit
stillmark coverage check "…" /stillmark coverage check "…" Check off a case by substring match
stillmark coverage uncheck "…" /stillmark coverage uncheck "…" Uncheck a case
stillmark coverage add "<heading>" "…" /stillmark coverage add "<heading>" "…" Add a tagged case under a heading
/stillmark coverage Print help only (no file changes)
/stillmark coverage <text> Free-text COVERAGE.md edits
/stillmark design … UI fixes; browser selection on your local dev preview
