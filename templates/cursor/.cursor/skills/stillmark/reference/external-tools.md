# External design tools

Use these when the host environment provides them. None are required for Stillmark design mode to run.

## Impeccable (optional)

Apache-2.0 skill with deep command playbooks (`critique`, `polish`, `audit`, ...). Install separately if available. `/stillmark` already runs an **automated** pipeline; invoke Impeccable only when the user asks for a specific Impeccable command or you need a playbook this skill does not cover.

## Vercel Web Interface Guidelines

MIT checklist for interface implementation quality (forms, animation, typography, performance hints). Use during the **verification** phase as a secondary pass after `reference/craft-floor.md`.

## UI/UX Pro Max / DesignSkills / similar

Treat as searchable design intelligence: palettes, patterns, stack notes. Supplement web research; do not skip live reference inspection for major work.

## Browser tooling

When MCP or IDE browser tools exist: navigate, snapshot, and screenshot real references and your running app. Never claim inspection you did not perform.
